# 261015_ncku_git

成功大學（NCKU）Git 練習專案。

## 簡介

這是一個用來練習 Git 與 GitHub 基本操作的專案，包含建立儲存庫、提交（commit）、推送（push）與協作流程。

## 目錄結構

```text
261015_ncku_git/
└── README.md    # 專案說明
```

## 快速開始

```bash
git clone https://github.com/SilviaLiou/261015_ncku_git.git
cd 261015_ncku_git
```

## 常用 Git 指令

| 指令 | 說明 |
|---|---|
| `git status` | 查看目前狀態 |
| `git add .` | 加入所有變更 |
| `git commit -m "訊息"` | 提交變更 |
| `git push` | 推送到 GitHub |
| `git pull` | 取得最新內容 |
